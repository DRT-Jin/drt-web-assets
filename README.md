# drt-web-assets

drtdrone.io 웹사이트용 이미지 리소스

## 사용법

이미지를 해당 폴더에 넣고 `git push`하면 끝.

URL 패턴:
```
https://raw.githubusercontent.com/DRT-Jin/drt-web-assets/main/{폴더}/{파일명}
```

예시:
```
https://raw.githubusercontent.com/DRT-Jin/drt-web-assets/main/nexa1/hero.jpg
```

## 폴더 구조

```
nexa1/          NEXA1 클리닝 드론
drt-q/          DRT-Q 국방/공공
drt-t/          DRT-T 국방/공공
drtview/        DRTView GCS
common/         공통 (로고, 배경 등)
```
