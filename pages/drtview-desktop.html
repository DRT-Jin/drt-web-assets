01 — Mission Planning

점을 찍는 대신,
범위를 지정합니다

웨이포인트를 하나씩 놓는 방식도 그대로 쓸 수 있지만, 넓은 지역을 훑는 임무라면 영역만 지정하고 간격과 각도를 정하면 경로가 만들어집니다. 측량용 격자, 도로·송전선 같은 회랑, 건물 외벽을 도는 다층 경로를 각각 지원합니다.

격자 측량

촬영 영역을 그리면 지정한 간격과 각도로 왕복 경로를 채웁니다. 선회 구간 길이와 카메라 촬영 트리거도 함께 설정합니다.

회랑 스캔

도로·하천·송전선처럼 길게 이어지는 대상을 폭만 지정해 따라갑니다.

구조물 스캔

건물이나 구조물 둘레를 고도를 나눠 여러 층으로 돕니다. 벽면과의 거리와 짐벌 각도를 지정합니다.

경계와 대피점

지오펜스로 비행 한계를 두고, 비상 착륙 지점(Rally Point)을 미리 지정합니다.

파일로 보관

.plan 파일로 저장하고 불러옵니다. 지오펜스와 대피점까지 한 파일에 담기며 QGroundControl과 호환됩니다.

소요 배터리

호버·순항 전류와 배터리 용량을 넣어 두면, 계획한 임무에 필요한 용량을 비행 전에 확인합니다.

plan_survey.png Plan 모드에서 격자 측량 경로가 생성된 상태. 왼쪽 설정 패널(간격·각도)과 지도의 왕복 경로가 함께 보이게.

영역을 그리면 경로는 자동으로 채워집니다.

plan_fence.png 지오펜스 폴리곤과 Rally Point가 지도에 표시된 상태. 오른쪽 목록 패널 포함.

비행 한계와 비상 착륙 지점을 같은 화면에서.

02 — Map

통신이 없는 현장에서도
지도는 열립니다

한 번 열어 본 위성 지도는 디스크에 남아 다음 비행에서 그대로 뜹니다. 직접 촬영한 정사영상을 올리면 현장 해상도 그대로 지도가 됩니다. 온라인 지도와 로컬 지도를 나란히 두고 비교할 수도 있습니다.

map_local_split.png 로컬맵 분할 보기 — 2분할 또는 4분할로 온라인 위성지도와 GeoTIFF 로컬맵을 나란히 띄운 화면. 레이어 패널이 보이면 더 좋습니다.

화면을 나눠 온라인 지도와 촬영 지도를 나란히 봅니다.

로컬 지도

GeoTIFF·COG 정사영상을 좌표에 맞춰 지도 위에 겹칩니다. 여러 장을 레이어로 쌓고 켜고 끕니다.

분할 보기

화면을 1·2·4분할로 나눠 서로 다른 지도를 동시에 봅니다. 온라인과 로컬을 반씩 붙여 보는 방식도 지원합니다.

타일 캐시

열어 본 지역은 디스크에 보관됩니다. 사용량 확인과 삭제는 설정에서 합니다.

공역 표시

비행금지·비행제한·관제권·주의공역을 지도에 겹치고, 구역에 들어가면 경고합니다. 인터넷이 없어도 내장 데이터로 표시됩니다.

map_airspace.png 공역 폴리곤이 색으로 표시된 지도. 구역을 눌러 이름·등급 말풍선이 뜬 상태면 가장 좋습니다.

공역은 색으로 구분되고, 눌러서 이름과 등급을 확인합니다.

03 — Connection

꽂으면 붙고,
여러 개를 한꺼번에

Pixhawk 계열 USB는 꽂는 즉시 인식해 연결합니다. 서로 다른 연결을 동시에 열어 둘 수 있고, 받은 MAVLink를 다른 지상국으로 그대로 넘겨줄 수도 있습니다.

UDP기본 14550 포트로 대기. 멀티캐스트 수신 포함.
TCP기본 5760 포트. 끊기면 자동으로 다시 붙도록 설정할 수 있습니다.
시리얼9,600 ~ 2,000,000 bps. Pixhawk·SiK 텔레메트리·RTK 수신기를 자동으로 찾습니다.
블루투스Windows 표준 직렬 프로파일로 바로 연결합니다. 가상 COM 포트를 따로 만들 필요가 없습니다.
중계받은 MAVLink를 다른 지상관제 프로그램으로 전달합니다. 한 대의 기체를 두 화면에서 볼 때 씁니다.
link_connect.png 연결 설정 화면 — 링크 목록에 두 개 이상이 연결된 상태(예: 시리얼 + UDP). 자동 감지된 포트 이름이 보이게.

필요한 연결을 필요한 만큼 열어 둡니다.

04 — Video

받은 화질 그대로
남깁니다

RTSP 스트림을 받거나, 전용 USB 수신기로 기체 영상을 직접 받습니다. 녹화는 다시 인코딩하지 않고 받은 스트림을 그대로 파일에 담습니다. 화질이 떨어지지 않고, 녹화 중에도 CPU가 놀지 않습니다.

두 가지 수신

일반 RTSP 스트림과, WFB-ng 방식의 직접 수신을 모두 지원합니다.

무손실 녹화

받은 영상을 재인코딩 없이 MP4로 저장합니다. 시동과 동시에 자동으로 녹화를 시작하도록 둘 수 있습니다.

화면 배분

지도와 영상 중 무엇을 크게 볼지 상황에 맞춰 바꿉니다. 작은 창은 크기를 끌어 조절합니다.

video_rec.png 영상을 크게 띄우고 녹화 중(REC 경과 시간 표시)인 화면. 지도는 작은 창으로.

시동을 걸면 녹화도 함께 시작하도록 둘 수 있습니다.

05 — Setup & Maintenance

기체를 맞추는 일도
여기서 끝냅니다

기체를 처음 세울 때와 정비할 때 필요한 절차가 모두 들어 있습니다. 모터가 어느 자리에 붙었는지, 스틱이 어느 채널인지 화면이 물어보고 순서대로 기록합니다.

모터 배치

모터를 하나씩 돌려 보고 어느 자리인지 화면에서 누르면, 배선 순서가 그대로 정리됩니다.

조종기 보정

스틱을 움직이면 채널을 스스로 찾아 최소·최대값과 기능 배정을 기록합니다.

센서 보정

자이로·가속도·수평·지자계·대기속도와 장착 방향을 순서대로 진행합니다.

파라미터

1,000개가 넘는 설정값을 검색·편집합니다. 저장해 둔 파일과 기체 값을 비교해 다른 항목만 골라 한 번에 적용할 수 있고, QGroundControl 형식과 호환됩니다.

OSD 편집

영상에 얹히는 정보의 위치를 격자 위에서 직접 옮겨 배치합니다.

콘솔

비행 컨트롤러 콘솔을 앱 안에서 바로 엽니다.

setup_actuator.png 모터 배치 마법사 — 기체 도형에 모터 번호가 표시되고 한 개가 선택된 상태.

돌려 보고, 눌러서 자리를 정합니다.

param_diff.png 파라미터 비교 창 — 파일 값과 기체 값이 다른 항목이 나열되고 체크박스로 선택된 상태.

달라진 값만 골라 한 번에 적용합니다.

06 — Records

비행은 두 벌로 남습니다

기체가 스스로 기록한 비행 로그를 목록에서 골라 내려받고, 지상국 쪽에서는 주고받은 통신을 자동으로 남깁니다. 문제가 생겼을 때 양쪽을 맞춰 볼 수 있습니다.

기체 로그

기체에 쌓인 비행 로그를 목록으로 확인하고 내려받습니다. 진행률이 표시되고 중간에 멈출 수 있으며, 저장 공간이 부족하면 한 번에 비웁니다.

통신 기록

시동을 걸면 기록이 시작되어 착륙과 함께 파일로 저장됩니다. 따로 누를 것이 없습니다.

영상 기록

녹화한 영상은 문서 폴더 아래에 날짜·시각 이름으로 정리됩니다. 저장 위치는 바꿀 수 있습니다.

log_download.png 로그 화면 — 비행 로그 목록과 다운로드 진행률이 함께 보이는 상태.

기체에 쌓인 로그를 목록에서 골라 내려받습니다.

Same App, Wider Screen

조종기와 같은 화면, 같은 조작.
넓은 화면에서만 되는 일이 더해집니다.

DRTView 조종기 버전과 나란히 쓰도록 만들었습니다.

07 — Install

설치는 한 번,
이후는 앱이 알아서

설치 파일 하나를 실행하면 끝납니다. 새 버전이 올라오면 앱이 알려 주고, 내려받은 파일이 온전한지 확인한 뒤 설치하고 다시 켭니다.

Windows x64

MSI 설치 파일 하나로 설치합니다. 관리자 권한 없이 사용자 계정에 설치됩니다.

Auto Update

새 버전을 앱 안에서 내려받고, 파일 검증을 거쳐 설치한 뒤 자동으로 다시 시작합니다.

Extras

게임패드로 직접 조종할 수 있고, 터치 노트북에서는 손가락 제스처로 지도를 다룹니다.
