DLACKBOX
DRT Flight Data Recorder

모든 비행은,
기록으로 말합니다

DLACKBOX는 드론 제조사 DRT가 만든 비행기록 분석 프로그램입니다.
기체에 저장된 비행 기록을 USB로 내려받아, 인터넷 없이 그 자리에서 완전한 분석 리포트를 엽니다.

01 — Collect

케이블 하나로,
수거가 끝납니다

기체를 USB로 연결하면 자동으로 인식하고, 기체 안의 비행 기록 목록을 불러옵니다. 필요한 기록만 골라도, 전체를 한 번에 받아도 됩니다. 전송 중 끊긴 구간은 자동으로 다시 요청해 채웁니다.

log_download.png 다운로드 진행 중 — 여러 로그가 선택되어 진행률이 움직이는 순간. 완료된 항목과 진행 중 항목이 같이 보이면 좋음.

받은 기록은 기체 번호와 비행 시각으로 정리되어 저장됩니다.

02 — Full Analysis

비행의 전부를,
인터넷 없이

PX4 커뮤니티의 표준 분석 도구 Flight Review의 전 항목이 프로그램 안에 들어 있습니다. 자세·고도·진동·전력까지 전체 플롯을 서버도, 인터넷도 없이 그 자리에서 엽니다. 다크·라이트 테마를 모두 지원합니다.

flight_review_full.png 풀 분석 창 — 플롯이 여러 개 보이도록 스크롤 중간 지점에서. 고도·자세 추종 플롯이 화면에 걸리게, 다크 테마.

분석 엔진과 그래프 라이브러리까지 전부 패키지 안에 있습니다 — 외부에서 가져오는 것이 없습니다.

03 — Readable

전문가가 아니어도
읽을 수 있습니다

리포트 맨 위의 추종품질 · 비행 요약 카드가 먼저 결론을 말합니다. 항목마다 수치를 3등급 색으로 판정하고, 무엇이 왜 문제인지 한국어로 풀어 씁니다.

추종 품질

조종 목표와 실제 움직임의 오차·지연·반응 크기를 수치로 재고 등급을 매깁니다.

진동 · 모터

기체 진동 수준과 모터 간 출력 편차로 정비가 필요한 상태를 짚습니다.

배터리 · 전력

비행 중 전압 강하와 소모 흐름을 요약합니다.

정직한 판정

손상된 기록은 그럴듯한 숫자를 만들지 않고 판정 보류로 알립니다 — 틀린 숫자보다 없는 숫자가 낫다는 원칙입니다.

quality_card.png 추종품질 · 비행 요약 카드 클로즈업 — 등급 배지(GOOD/WARN)와 한국어 해설 문장이 보이게. 실비행 로그로, 등급이 섞여 있는 컷이 이상적.

등급 색과 해설이 리포트의 첫 화면입니다.

Air-gapped by Design

인터넷이 닿지 않는 곳에서도,
분석은 완전해야 합니다.

04 — Closed-network Security

폐쇄망을 위해
설계됐습니다

license_qr.png 라이선스 활성화 화면 — 인증 코드 QR이 표시된 상태. 실제 HWID 문자열은 일부 가려도 됨.

활성화도 오프라인 — 화면의 QR을 읽어 현장에서 끝냅니다.

네트워크 코드 없음

외부 접속을 막은 것이 아니라, 접속을 시도하는 코드 자체가 없습니다. 보안 검수에서 그대로 확인됩니다.

오프라인 라이선스

설치 PC의 하드웨어에 묶인 라이선스를 서명 파일로 발급합니다. 다른 PC로 복사해도 동작하지 않습니다.

기간 통제

영구·기간 라이선스를 모두 지원하고, 계약 기간은 만료일로 통제됩니다.

완전 자급 패키지

분석 엔진을 포함한 모든 구성 요소가 패키지 안에 있어, 반입 후 추가로 설치할 것이 없습니다.

05 — Zero-friction Setup

설치한 뒤에는,
손 갈 일이 없습니다

드라이버 동봉

기체 연결에 필요한 USB 드라이버가 패키지에 들어 있고, 필요할 때 프로그램이 알아서 설치합니다.

관리자 승인 최소화

설치 한 번으로 준비가 끝나고, 이후 일상 사용에서는 관리자 승인 창이 뜨지 않습니다.

두 가지 형태

설치형과 무설치 포터블을 함께 제공합니다. CD·USB로 반입해 어느 PC에서든 바로 실행할 수 있습니다.

installer_wizard.png 설치 마법사 — 브랜딩 배너가 보이는 첫 화면 또는 완료 화면.

설치부터 드라이버까지, 한 번의 진행으로 끝납니다.
